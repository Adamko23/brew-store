First public preview of Brew Store, a Rust desktop manager for Homebrew.

- Live local search across Homebrew formulae and casks.
- Real installed inventory, local app icons and measured installation sizes.
- Install, uninstall, update and Update All through confirmed Homebrew commands.
- Open installed applications and inspect package dependencies.
- Native light/dark appearance, English/Slovak localization and the beer icon.
- Command Line Tools diagnosis and compatible Apple update installation.

## Download and install

**Apple Silicon (arm64), macOS 13+, working Homebrew required.**

Download the DMG, drag Brew Store to Applications, eject the image and launch
the app. The ZIP contains the same app bundle. Verify downloads using the
attached SHA-256 checksum file.

This preview is ad-hoc signed and **not notarized by Apple**. The first launch
may require the per-app **Open Anyway** option in System Settings > Privacy &
Security. See [Apple's instructions](https://support.apple.com/102445).

## Validation and current limits

The release is checked with Rust formatting, 60 behavioral tests, strict Clippy,
code signature verification and DMG verification. Package mutation tests use
fake processes. The public binary is built for Apple Silicon; Intel users can
build the source on their Mac. VoiceOver support remains incomplete.

Update All reports the outcome of one `brew upgrade` command. Some packages may
change before that command fails; the app reconciles the current Homebrew state.
The in-app log retains the latest 400 lines.
