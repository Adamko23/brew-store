Local installation and signed automatic application updates.

- Sparkle 2.10.1 checks for app updates on launch and daily while the app runs.
- Updates download in the background and install on quit when authorization is
  not required. A native "Check for App Updates…" menu item is also available.
- The update feed and archives are Ed25519 signed. Archives are verified before
  extraction; system profiling is disabled.
- The UI and application remain Rust + Iced. Sparkle is a bundled native framework.
- Local bundle builds and public release packaging verify nested signatures.
- Public packaging now requires Developer ID and notarization by default;
  non-notarized releases require the explicit `--preview` option.

**Apple Silicon, macOS 13+, Homebrew required.**

This release remains an **ad-hoc signed, non-notarized preview**. A new download
may require the per-app first-launch approval described in
[Apple's instructions](https://support.apple.com/102445). Update signatures
protect Sparkle updates; they do not constitute Apple notarization.

Version 0.1.0 does not contain an updater and needs a one-time update to this
version. Future releases published to the signed appcast can update in-app.
